I've wanted a place to write up the smaller things that don't earn a whole project page — a debugging war story, a note on a tool, a "this took me three hours, here's the one line that fixed it."

This is that place. Posts live as markdown files in `posts/`, and a small Node script turns them into pages that match the rest of the site.

A code block, since you'll see plenty of these:

```bash
npm run build:blog
```
